# 資訊館漫遊

大甲高工資訊科館的繁體中文網頁探索遊戲原型。以原生 HTML、CSS、JavaScript 與 SVG 製作，不需要下載套件或 API 金鑰。

## 執行

在此專案目錄執行 `npm start`（需要 Python 3），使用瀏覽器開啟 `http://localhost:3000`。亦可將專案檔案放在任何靜態網站伺服器。

## 玩法

選擇男生或女生，輸入三至四個中文字的暱稱。左右方向鍵移動，上下方向鍵沿樓梯換層；靠近教室或主任按 E 互動。也可點選教室門口、主任、側欄樓層與畫面下方控制鈕。進入教室後，點「回到長廊」或按 E / Escape 離開。

科主任每約 13 秒換到下一層巡樓；同一層時點選他就能對話，未完成全部任務時會從十句指定台詞隨機選一句；完成八項任務後改為頒發個人邀請函。對話、角色設定與任務期間暫停巡樓。任務完成進度儲存在瀏覽器 localStorage；重新選角並開始會重置進度。

一樓辦公室與選手室面積為 2:1；二至四樓兩間教室均分。外觀依參考照片抽象化呈現灰牆、紅磚、欄杆、拱形長廊與斜屋頂，並非建築測繪。A201 已加入「單晶片微處理機實習」、A202 已加入「程式設計實習」、A301 已加入「可程式邏輯設計實習」；A302 已加入「電腦網路實習」的硬體組裝體驗；A402 已加入「基本電學實習」；A401 已加入「電子學實習」的非反相 OPA 放大體驗。

## 驗證

`npm test` 驗證名稱、教室配置、各課程模擬器、邏輯閘真值表、八項任務通關計數與邀請資格與天氣資料處理。

## A202：程式設計實習

進入二樓 A202 會先顯示課程介紹，按「開始任務」再進入程式設計實習編輯器，不顯示教室桌椅布局。任務選單可隨時再次查看介紹並返回原任務；依三步驟輸入 C 語言的 Hello, World! 程式，按「執行程式」或 Ctrl / Command + Enter 查看輸出與修正提示。成功輸出後顯示「任務完成！」。任務上方「離開教室」、完成區的離開按鈕或 Escape 都會關閉任務並回到長廊。離開前會自動保存草稿，再進入可續寫。

這是只辨識本課 C 語法的教學模擬器，並非通用 C 編譯器，不會執行使用者輸入的任意程式碼。允許空白、註解、`main(void)` 或 `main()`，要求一次 `printf`、指定文字及 `return 0;`。草稿依角色姓名和性別儲存在本機瀏覽器，離開再進入可續寫。

執行 `python3 scripts/build-standalone.py` 會將最新版完整遊戲輸出至專案上一層的「資訊館漫遊.html」，可作為單檔遊戲使用。

二至四樓的左右教室位置已互換，名稱與代號維持對應：二樓左 A202 應用軟體、右 A201 微電腦；三樓左 A302 電腦網路、右 A301 週邊電路；四樓左 A402 基電、右 A401 電子。

## A201：單晶片微處理機實習

進入 A201 先顯示單晶片微處理機實習課程介紹，按「開始任務」再進入 Arduino LED 任務。選 LED 長腳（＋），點 D10；選短腳（－），點 GND，限流用的 220Ω 電阻已串接在長腳路徑上。輸入 `setup()`、`loop()`，先 `pinMode(10, OUTPUT);`，再 `digitalWrite(10, HIGH);`，執行後必須接線和程式都正確才會點亮 LED 並顯示任務完成。可使用 `const int ledPin = 10;` 這類腳位變數。修改接線或程式後需重新執行；草稿與接線依角色保存在瀏覽器。點離開教室或 Escape 回到長廊。

模擬器僅支援本課的 Arduino 語法，不執行任意 C++ 或連線實體硬體；本課不支援延遲、迴圈敘述等進階語法。

## 日期與大甲區氣溫

日期使用 `Asia/Taipei`，每分鐘更新。氣溫取用 Open-Meteo（大甲區中心附近 24.35°N、120.62°E）的當前座標格點估計值，每十分鐘更新，不是校內溫度計的即時測量。來源與資料時間可從溫度文字的提示查看。網路須允許 HTTPS 至 `api.open-meteo.com`；不需 API 金鑰，且保留頁尾來源連結。

請求失敗、無效資料或超過兩小時的資料一律顯示「大甲區溫度暫無資料」，不會顯示固定示範值。下載的單檔遊戲也需要網際網路才能取得氣溫；離線仍可遊玩課程。


## A301：可程式邏輯設計實習

進入三樓右側 A301 先顯示可程式邏輯設計實習課程介紹，按「開始任務」後開啟任務。三組各自獨立的電路都已接好，指撥開關可用滑鼠、觸控或鍵盤 Enter / Space 切換 0 與 1。LED 與真值表目前列會即時更新，表示式與規則始終顯示。

目標為 AND 亮、OR 不亮、NOT 不亮；解答分別為 AND 的 A、B 都是 1，OR 的 A、B 都是 0，NOT 的 A 是 1。必須按「檢查結果」確認三組同時達成才記錄任務完成。可重設開關、重複練習，點離開教室或 Escape 返回長廊。

## 八項資訊館任務進度

進度包括辦公室與選手室參訪，以及 A201、A202、A301、A302、A401、A402 六個工場，共八項任務。參訪介紹返回長廊時計入完成；工場須通過任務檢查才完成。重複參訪或通關不重複計數，已取得的完成紀錄不會因再次練習失敗而撤回。導覽圓點與門牌勾號反映八項任務完成狀態。

全部完成顯示 8 / 8（100%），側邊主任卡提醒前往對話。按卡片按鈕可前往主任所在樓層，再點主任或用鍵盤互動領取「歡迎加入大甲高工資訊科」邀請函，包含角色中文暱稱；可再次對話查看。尚未完成時維持十句隨機鼓勵對話。

舊存檔中的工場通關紀錄保留，辦公室／選手室既有參訪紀錄會補計；單純拜訪過工場不等於完成課程。完成紀錄與邀請函領取狀態儲存在瀏覽器，重新整理保留，重新選角並開始則重置。

六門已開放課程的任務選單均有「課程介紹」與「離開教室」。課程介紹可重複開啟，按「繼續任務」保留原本的程式、接線、開關及檢查結果。亮燈目標以加大的琥珀色文字顯示，不亮燈目標以加大的藍色文字顯示。

## A302：電腦網路實習（硬體組裝體驗）

進入三樓左側 A302，先閱讀課程介紹，再開始任務。元件卡介紹 CPU、RAM 記憶體、顯示卡，以及 M.2 NVMe SSD 的功能。選取元件後依提示點選插槽，或用滑鼠拖曳安裝：CPU → CPU 插座、記憶體 → DIMM、顯示卡 → PCIe x16、SSD → M.2。選取與安裝都支援鍵盤 Enter；手機可點選。

不相容位置會顯示提示且不會安裝。四種元件皆正確安裝後，按「檢查組裝」才通關並計入八項資訊館任務完成進度。可點板上元件卸下，或按全部卸下重練；已取得的通關紀錄不會撤回。組裝草稿依角色保存在瀏覽器；重看介紹、離開再進入可接續。

主機板是簡化的斷電俯視模擬，並非完整可開機的電腦實作。實體組裝另有散熱、供電等步驟；本關重點為辨認元件及相容插槽。

## A402：基本電學實習

進入四樓左側 A402，先閱讀課程介紹，再依序進入「認識麵包板 → 觀察電路 → 判斷串並聯」。麵包板教學有同組五孔、中央溝槽、電源軌與跨接導線四種圖解，以及可放大、左右捲動的孔位示意圖；接著才會顯示固定電路，最後按「開始判斷」才顯示答案選項。兩組麵包板都已接好兩顆燈泡與已開啟的 6V 直流電源，不需接線。圖中每一列直向五孔為一組內部相通的接點，中央溝槽兩側各自獨立；彩色跨接線只在端點插入麵包板。

觀察從電源＋端經燈泡返回－端的路徑，再替電路 A、B 選串聯或並聯。A 是串聯，電流依序經過兩顆燈泡；B 是並聯，每顆燈泡各在一條支路上。兩題都選對並按「檢查答案」才計入通關。漏答、答錯或只答對一題都不會完成，會提供逐題回饋；可重新作答、重看介紹並保留答案，或離開教室。答案依角色存在瀏覽器，重複通關不重複計分。

燈泡亮度及電路外觀為簡化示意，應依接線拓樸判斷，不以亮度作為唯一依據。實體電路應先關閉電源再接線並經老師確認。

A402 的任務選單另有「麵包板圖解」，可隨時返回教學。返回圖解、電路觀察或課程介紹都不會清除已選答案；只有最後作答階段能檢查通關。


## A401：電子學實習（非反相 OPA 放大器）

進入四樓右側 A401，先看課程介紹，再以示波器觀察固定的 1 kHz、0.50 V 峰值（1.00 Vpp）、零直流偏壓正弦波。放大是讓訊號振幅變大，不改變頻率；非反相放大器的正負方向也維持不變。

題目固定為放大 4 倍，目標在示波器螢幕上明確標示，並以白色虛線畫出。CH1 為青色輸入波形、CH2 為黃色輸出波形；兩通道同為 1 V/div，時基為 0.2 ms/div，畫面共兩個週期。電壓數字同時顯示峰值與峰對峰值，避免混淆。

固定 Rin（亦稱 Rg）= 10 kΩ，接在 OPA 負端與地之間；正端直接接訊號。負迴授可變電阻 Rf 則從輸出接回負端。公式 Av = 1 + Rf/Rin、Vout = Av × Vin。Rf 以滑桿、加減鈕或整數輸入調整，範圍 0～50 kΩ、每格 1 kΩ。Rf = 30 kΩ 時 Av = 4，輸出為 2.00 V 峰值（4.00 Vpp），會立即自動通關，不需要再按檢查。錯誤或不合法的電阻值不會通關。

電路圖使用 OPA 三角形、電阻／可變電阻及接地符號；訊號產生器與示波器採儀器外觀概念圖。理想 OPA 供電 ±12 V，允許調整範圍內輸出不超過 3 V 峰值，未進入削波；實體放大器的頻寬與非理想特性未納入這一關。

重看介紹不會清除電阻值；依角色保存 Rf 草稿，重新體驗會回到 Rf = 10 kΩ。已取得的通關紀錄不會因再次調整或重設而撤回。

進入選手室自動開啟介紹，說明本科經常獲獎，以及歷年選手透過技優推甄與推薦甄試錄取國立科技大學。列出全國工科技藝競賽（電腦修護、電腦軟體設計、機械手臂技術）、全國技能競賽（資訊網路技術、機器人系統整合、網頁設計）、全國技術型高級中等學校學生團隊技術創造力培訓與競賽、全國高級中等學校小論文寫作比賽、全國專題實作競賽。

## 公開至 GitHub Pages

`.github/workflows/pages.yml` 會在推送至 `main` 時先驗證遊戲，再發布 `scripts/build-site.py` 產生的靜態網站。網站內容僅包含 HTML、CSS 與遊戲模組。GitHub 儲存庫的 Settings → Pages → Build and deployment → Source 請選 **GitHub Actions**；設定後可到 Actions 執行 **Publish game to GitHub Pages**。

發布成功後，網址預期為 `https://cindejhang.github.io/-/`，實際網址以部署工作輸出為準。
